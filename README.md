# Sorteador de Números

Este projeto foi desenvolvido de forma prática através de um desafio da plataforma Rocketseat. Trata-se de um sorteador de números onde você define a quantidade e o intervalo dos valores a serem gerados.

<img width="1280" height="720" alt="Sorteador de Números" src="https://github.com/user-attachments/assets/adebfa2d-b0be-460e-878d-8ddad6c740eb" />

## Funcionalidades

*   Definição da quantidade de números que serão sorteados no primeiro campo.
*   Configuração do intervalo do sorteio, definindo o valor mínimo (início) e o valor máximo (fim).
*   Opção para ativar ou desativar a repetição de números no sorteio através de um botão alternador.

## Tecnologias Utilizadas

*   **Front-end:** HTML, CSS e JavaScript.
